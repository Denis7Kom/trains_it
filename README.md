# BINARIO

Интерактивный гид по поездам Италии: категории, конструкция, пассажирские пространства,
билеты и основные направления. Статический сайт для GitHub Pages.

[Русский](https://denis7kom.github.io/trains_it/?lang=ru) ·
[English](https://denis7kom.github.io/trains_it/en/) ·
[Italiano](https://denis7kom.github.io/trains_it/it/)

## Структура

```text
index.html                  Русская версия
en/index.html               Английская версия
it/index.html               Итальянская версия
scripts/site-tools.mjs      Разбор, форматирование и контроль содержимого страниц
scripts/format.mjs          Форматирование встроенных CSS и JavaScript
scripts/verify.mjs          Проверка сохранности разметки, стилей и логики
scripts/site-baseline.json  Контрольные отпечатки трёх страниц
.github/workflows/quality.yml
```

Каждая языковая версия — самостоятельный HTML-файл со встроенными стилями, данными
и кодом. Такая структура сохраняет существующие URL и способ публикации. Сборка
для запуска и размещения сайта не требуется.

## Локальный запуск

Откройте `index.html` в современном браузере или используйте любой локальный
статический HTTP-сервер. Для загрузки Three.js и веб-шрифтов нужен интернет.
При недоступности WebGL предусмотрена SVG-иллюстрация.

## Проверки для разработки

Нужны Node.js 22 или новее и npm. Зависимости используются только при разработке:

```sh
npm ci
npm run format
npm run check
```

Форматирование ограничено содержимым исполняемых `<script>` и `<style>`. Остальная
HTML-разметка сохраняется побайтно: переносы и пробелы могут влиять на отображение
текста и SVG. Версия Prettier зафиксирована в `package-lock.json`.

`npm run check` проверяет единый стиль и соответствие контрольному состоянию:

- HTML-разметка, тексты, атрибуты и встроенные SVG;
- структура JavaScript после разбора в AST, включая значения строк и данных;
- CSS после приведения к единому формату с сохранением порядка правил.

AST — синтаксическое дерево программы. Проверка не учитывает отступы, кавычки
и комментарии, но обнаруживает изменение выражений, обработчиков и данных.
Она не заменяет визуальную проверку браузера, тестирование WebGL или измерение
производительности.

При намеренном изменении сайта сначала проверьте результат во всех трёх языковых
версиях. Затем выполните `npm run baseline:record` и отдельно просмотрите изменение
`scripts/site-baseline.json` перед коммитом. При рефакторинге без изменения поведения
контрольное состояние обновлять не следует.

## Работа со страницами

- Данные поездов и тексты находятся в объектах соответствующей языковой страницы.
- SVG-карточки формируются отдельно от интерактивной 3D-сцены.
- Станция, модели поездов и управление камерой находятся в модуле Three.js.
- Изменения функциональности переносите во все три версии; названия брендов и
  служебные идентификаторы не переводятся.

## Публикация

GitHub Pages публикует HTML непосредственно из репозитория. Workflow `Source quality`
выполняет проверки при push и pull request; он не изменяет настройки публикации.

Иллюстрации и карта схематичны. Транспортные характеристики и правила поездки
проверяются по ссылкам операторов, указанным на сайте.
